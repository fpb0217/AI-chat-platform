# Local AI Chat Platform

一个本地运行的 Vue 3 + Fastify 多会话 AI 对话应用。它通过 SSE 接收 DeepSeek 流式输出，在浏览器中平滑呈现打字机效果，并使用本地 SQLite 持久化会话、消息、推理过程与自动标题。

## 本地启动

1. 安装 Node.js 24+ 与 pnpm 11+。
2. 复制 `.env.example` 为 `.env`，填写 `DEEPSEEK_API_KEY`。
3. 执行 `pnpm install`。
4. 执行 `pnpm db:migrate`。
5. 执行 `pnpm dev`，访问 `http://127.0.0.1:5173`。

生产模式可执行 `pnpm build` 后运行 `pnpm start`，访问 `http://127.0.0.1:3000`。

## 会话管理

- 桌面端左侧栏和移动端抽屉展示所有非空会话，并按最近消息时间排序。
- “新对话”使用延迟创建，发送第一条消息时才写入 SQLite，不产生空会话记录。
- 会话支持切换续聊、手动重命名和二次确认删除；最后选择保存在浏览器本地偏好中。
- 每轮回答完成后使用 `deepseek-v4-flash` 无思考模式生成自动标题；标题建议为 20～40 个字符，服务端硬限制为 48 个 Unicode 字素。
- 手动标题最多 60 个 Unicode 字素，保存后不会被后续自动标题覆盖。

## 推理强度

顶部模型选择器支持关闭、低、高、最大四档 DeepSeek V4 Flash 推理强度。默认保持关闭；选择结果只作为本地偏好保存，每条 assistant 消息会记录实际使用的档位和可用的推理 Token。思考模式会在最终回答前实时展示可折叠的“思考过程”，开始回答后自动折叠；完成、停止、错误及刷新后会从本地 SQLite 恢复已经生成的内容。无工具调用时，历史思考过程不会加入下一轮模型上下文。

## 主题

- 顶栏主题按钮支持在浅色与深色模式之间切换，桌面端和移动端均可通过鼠标、触摸或键盘操作。
- 首次访问固定使用浅色主题，不跟随操作系统；选择保存在浏览器 localStorage 的 `ai-chat.theme.v1` 中。
- 页面会在 Vue 挂载前恢复上次选择，并同步 `data-theme`、原生 `color-scheme` 与浏览器 `theme-color`，避免深色刷新时闪现浅色界面。
- 浏览器存储不可用或保存值非法时安全回退到浅色，不影响会话、消息、输入草稿、推理强度或生成状态。
